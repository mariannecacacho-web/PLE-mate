# PLE-mate FREE

A free-first, static PLE study dashboard.

## What it includes
- Two-column dashboard with PLE-mate companion area
- Add/edit/remove subjects
- Hours planned, studied, and remaining
- Study-session history
- Weekly study-hours graph
- Detailed progress page
- Countdown
- Calendar page
- Local calendar events
- Basic `.ics` import for all-day events
- Virtual corkboard
- Persistent browser storage via localStorage
- JSON export/import backups
- Controlled PLE-mate changes that can be generated by ChatGPT
- No OpenAI API key required
- No backend required

## Important limitation
This free version does not embed ChatGPT or automatically receive messages from ChatGPT. The "Open ChatGPT" button opens the real ChatGPT website. For dashboard changes, ask ChatGPT to output a PLE-mate change JSON and paste it into "Apply a PLE-mate change."

Example:
{"type":"ADD_SUBJECT","name":"Pathology","hours":40}

Other supported changes:
{"type":"LOG_STUDY_TIME","subject":"Surgery","hours":3}
{"type":"SET_HOURS","subject":"Medicine","hours":20}
{"type":"COMPLETE_SUBJECT","subject":"Pediatrics"}
{"type":"SET_PRIORITY","subject":"OB-GYN","priority":true}
{"type":"ADD_PIN","text":"Keep going. One day at a time."}
{"type":"ADD_CORKBOARD_NOTE","text":"I can do hard things.","author":"Future me"}
{"type":"SHOW_HOURS"}
{"type":"DELETE_WIDGET","widget":"hours"}
{"type":"SORT_WEAKEST"}

## Data
Your data is stored in this browser. Use Export backup regularly. If browser storage is cleared, restore from your JSON backup.

## GitHub Pages
This app can be hosted as a static site, including GitHub Pages. It does not need server-side code.
